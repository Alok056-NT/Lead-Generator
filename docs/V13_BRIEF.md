# v1.3 brief (owner feedback 25 Oct, after trying v1.2). Fast, low-credit, nothing that works may break.

1. **Coherent structure.** One-time, app-wide things live OUTSIDE projects: Connect your AI (Claude plan or API key, plus the chat model: default **Sonnet 5.5, high effort**, changeable), Connectors (all keys), Usage. Everything that varies per project lives INSIDE the project: product/content, sender identity, contact memory/cooldown, old contacts, campaigns, message templates, results. Research good onboarding → home → workspace flows and arrange the site accordingly.
2. **Look**: recreate the design language of ElevenLabs UI (https://github.com/elevenlabs/ui: spacing, cards, chat/agent components, orb/wave/progress visuals, motion) in our plain HTML/CSS/JS (no React, no build step, no CDN). Apple-like calm, minimal scrolling.
3. **Connectors by segment** (keys page grouped): *Search* (Serper, Brave, plus others the research finds free), *Email & phone finding from a LinkedIn profile* (**Apollo** people match by LinkedIn URL; Prospeo / GetProspect or similar if they have a usable free API), *Email verification* (Reoon, ZeroBounce, Emailable…), *Sending* (mailbox, lemlist). Official APIs with the user's own keys only (no scraping LinkedIn itself). Any found email still goes through verification before it counts; phone numbers are shown as "found, not verified". Respect each API's credit costs and ask before spending.
4. **Sign-off**: messages end with a proper block on separate lines: name / designation / company (project's sender identity: name, designation, company, all editable). Fix drafting and add a check.
5. **Message templates**: built-in templates by receiver level (C-suite / Director-Head / Manager) × depth (short / standard / detailed: how much about the receiver and the sender to include), each with a one-line use case; the user can write and save their own template with placeholders; a campaign picks one; the AI drafts following it.
6. **Collapse / expand / layout**: every card and panel can collapse/expand; layout switch where useful (e.g. chat wide / results wide / side by side); the page remembers each card's state (local per browser); minimal scrolling.
7. **Usage meter**: show the AI usage of this app (tokens and cost per chat turn, per project, today) from Claude Code's own result data, and the current model/effort.
8. **Visible process**: the AI's working steps (thinking, each tool call, progress) shown as an engaging live timeline/visual next to the chat.
9. Keep v1.2 behaviour: chat engine, verified-only emails, contact memory, checks before export, nothing sent without a click.
