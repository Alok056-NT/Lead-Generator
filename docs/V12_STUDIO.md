# v1.2 "Studio": one-stop web app with the AI inside (deadline Monday 26 Oct morning IST)

Owner brief (25 Oct): a non-technical person installs once, clicks **one button**, and a web page opens with their **projects**. Inside a project they **chat with the AI** they connected; the AI asks only for the essentials and does everything else itself with Lead Generator's tools, showing verified contacts (LinkedIn + email) and a written message per person, then exports or (after approval) sends. Apple-style design. **Credits are nearly gone until Friday: build fast, test once, keep everything that works.** Security hardening is later, but never weaken the existing safety rules (loopback only, X-LeadGen header + same-origin on changes, no secrets returned, no real people in the repo).

Reuse everything built in v1.0/v1.1 (services, MCP tools, dashboard API, guides). Harvey's `reference/harvey/` and `D:\Claude Files\harvey\harvey\brain.py` show how to run Claude Code headless on a user's plan.

## The flow the person sees
1. **Desktop button "Lead Generator"** (created by the installer; Start menu too). Click → starts the local server if needed → opens the browser at the app.
2. **First open only: "Connect your AI"** screen, two big choices:
   - **Use my Claude plan** (Pro/Max): checks Claude Code is installed (if not: one button that shows the exact install command / link), then a **Sign in to Claude** button (runs the CLI's own login so the browser opens Anthropic's page), then **Test** ("Connected").
   - **Use an API key**: paste an Anthropic API key (stored in `secrets.env` as `ANTHROPIC_API_KEY`, masked), **Test**.
   Changeable later in Settings.
3. **Home = Projects**: big cards (name, one-line about, contacts ready, verified emails, last activity) with **Open**, **Edit** (name, sender name, "don't contact again for N days"), **Delete** (type the project name to confirm; removes the project and its campaigns, people, messages and contact memory). **New project** button: only a name.
4. **Project page** = two panes:
   - **Left: chat** with the AI (streaming replies, attach files: brochure/catalogue PDF/Word/text, old contacts CSV/Excel; quick-reply chips the AI can offer such as "Yes, go ahead").
   - **Right: progress + results**: a stepper (Your product → Who to reach → Companies → People → Emails → Messages → Checks → Export / Send) that fills in from real data; a results table of **ready contacts**: name, job, company, LinkedIn link, verified email (only verified), the LinkedIn message and the email (subject + body) written for that person; **Export** (lemlist CSV / Excel-friendly CSV); **Connect email** (existing mailbox help page) and **Connect lemlist** (key); **Send** buttons that always show a confirmation with the count and need a click (the AI can never send on its own).
5. **What the AI asks** (and nothing else, one thing at a time): (1) the product/content (website link with "one page / whole website", or a file, or pasted text); (2) the **sender name for the sign-off** (stored on the project, editable any time); (3) email, LinkedIn or both; (4) optionally old contacts to skip or use as warm leads. Everything else it **works out itself** from the content (countries, sectors, job roles, company list, size limits with sensible defaults) and shows as one short summary with a "Looks good" chip; the person can correct in plain words. It never asks for API keys in chat: it shows a button to the Keys page. Free mode (its own web search) is not available inside this chat in v1.2; if no search key is set it asks the person to add the free Serper key via the button.

## Technical shape (designer turns this into exact specs)
- **Chat engine** `services/chat.py`: one turn = run `claude -p <message>` with `--output-format stream-json` (plus whatever flags the installed CLI requires for streaming; verify with `claude --help`), `--mcp-config <workspace file pointing at this Python's "-m leadgen mcp">`, `--strict-mcp-config`, `--tools ""` (no built-in tools: no files, no shell), `--allowedTools` the Lead Generator MCP tools only, `--append-system-prompt-file <studio guide>` (workflow guide + the rules above + the project's id and sender name), and a per-project Claude session (`--session-id` on the first turn, `--resume` after) stored in the DB. API-key mode = same command with `ANTHROPIC_API_KEY` in the child's environment. Executable from `LEADGEN_CLAUDE_BIN` env (default `claude` on PATH, else `~/.local/bin/claude(.exe)`), so tests use a **fake claude script** that prints recorded stream-json. One turn at a time per project; Stop button kills the child; no shell=True; never log message text or keys.
- **Streaming to the page**: Server-Sent Events from FastAPI (`text/event-stream`), events: text delta, tool started/finished (shown as small grey "Finding people…" lines), turn done, error (plain English: not signed in, usage limit reached, network).
- **Data** (migration, forward-only, keeps all data): `projects.sender_name` (text, default ""), `chat_messages` (project_id, role user/assistant/tool, text, at), project's Claude session id; settings `ai_mode` (`claude_plan` / `api_key`). Drafting uses the project's sender name for the sign-off.
- **Uploads**: saved under the workspace `uploads/<project_id>/`; the chat message sent to the AI names the file path so it calls `ingest_offer_source` / `import_contacts`.
- **Launcher**: `leadgen app` (start the dashboard detached if not running via the existing `dashboard_ctl`, then open the browser). Installer creates Desktop + Start-menu shortcuts on Windows (`.lnk` via PowerShell `WScript.Shell`) and a `Lead Generator.command` on the macOS Desktop.
- **Design**: Apple-like: system font stack (`-apple-system, BlinkMacSystemFont, "SF Pro Text", "Segoe UI Variable", "Segoe UI", system-ui, sans-serif`), lots of white space, 14–20 px rounded cards, soft shadows, frosted top bar (`backdrop-filter`), one accent colour, 150–250 ms ease transitions, big friendly buttons, light and dark, works at laptop and tablet widths, keyboard accessible. No CDN, no build step (plain HTML/CSS/JS like today). Existing pages stay reachable under **Advanced**.
